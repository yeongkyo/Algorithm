### 문제 설명

<p>Раскрыв документ, Эркюль был разочарован --- список был разорван на две части, и детектив держал в руках только одну из них. <p>Чтобы распутать дело как можно скорее, Эркюлю Пуаро необходимы инструменты для быстрого подсчета. Помогите детективу восстановить потерянный документ, а именно тип каждой операции, пользуясь известными данными о нем. До совершения указанных операций бюджет жертвы состоял из 0 монет. Если операция является доходом, суммарное количество средств увеличивается на величину операции, если расходом --- уменьшается.</p>
